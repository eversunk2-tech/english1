## 1. 사용자 요청 (원문)
> 5,6학년 아이들이 단어가 너무 쉽다는 피드백이 왔는데, 단어의 수준도 좀 더 높여줘. 지금은 너무 쉽다고 해

## 2. 상황
- spec v2(난이도 Easy/Normal/Hard + 오답 감점)는 사용자 승인 뒤 **Build가 지금 구현 중**이다. v2 설계(속도표, 최소 시간 식, 감점)는 이번에 바꾸지 않는다.
- 지금 5~6학년군 77문항(부록 A)은 2022 개정 [별표 3]의 초등 권장(*) 800 낱말 안에서 골랐다(cat, lion, bread 같은 기초 낱말이 많음). 설명 문장도 초등 어휘 비율·낱말 수 상한(V1~V9) 규칙을 따른다.

## 3. 너의 일 — 설계하고 spec.md에 [추천]으로 반영 (사용자 승인 전)
1. **단어 수준을 높이는 기준**을 정한다. 갈림길 예:
   - 초등 권장 800 낱말 안에서 더 어려운 것(추상어, 긴 낱말, 덜 자주 쓰는 것: 예 library, museum, weather, favorite, dangerous, borrow …)만 쓰기
   - 2022 개정 기본 어휘 중 중학교 수준(* 없는 낱말) 일부를 5~6학년 "심화"로 넣기
   - 섞기
   각 안의 근거(교육과정 원문, 실제 5~6학년 교과서 수준), 장단점, 추천을 적는다. 교육과정 원문(부록 C 주소)을 다시 확인한다.
2. **5~6학년군 문항을 다시 만든다**: 쉬운 기초 낱말은 3~4학년군으로 옮기거나 빼고, 더 어려운 낱말로 채운다. 5~6학년군 문항 수는 지금(77)보다 줄지 않게(가능하면 80 이상). 3~4학년군은 이번 요청 대상이 아니므로 크게 바꾸지 않는다(5~6에서 옮겨 오는 것만).
   - 설명(clue)은 정답보다 쉬운 말로 — 5~6학년이 읽을 수 있어야 한다. 설명 어휘 기준(V 규칙)을 5~6학년 심화 문항에 맞게 조정해야 하면 그 규칙과 근거를 적는다.
   - 7절 품질 기준(H1 정답 하나만, H2 자연스러운 영어, H3 한국어 뜻, H4 동사·형용사)을 지키고, Review v1에서 나온 함정(같은 판에 함께 맞는 카드)을 판 구성 흉내(학년군별 씨앗 5,000개, v2 난이도 규칙 포함)로 확인한다.
   - 새 낱말은 v2 최소 떨어지는 시간 식(설명 낱말 수 기반)과도 맞물린다 — 설명이 길어져 Hard가 너무 느려지지 않는지 확인.
3. **"모두" 학년군**, 학년군×난이도 조합에서 단어 수준이 어떻게 보이는지 정리.
4. 바뀌는 데이터·검사(vocab 파일, V1~V9 규칙, data.test, check:data)와 Build 할 일(작은 단계·완료 기준).
5. **사용자 확인 필요**에 갈림길과 추천.
