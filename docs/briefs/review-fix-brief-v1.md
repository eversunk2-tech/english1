## 3. 확인할 것
1. `npm run check` 직접 재현, 숫자 기록.
2. **M1**: 지난번 재현 순서(한 판 끝 → [다시 하기]·AGAIN 카드 둘 다 → 0.5초 뒤 hidden → 보임 → 이어 가기)를 Review가 직접 다시 돌려 멈추지 않는지. Build는 새 E2 테스트가 고치기 전 코드에서 "멈춤" 확인 줄이 아니라 앞선 설명 띠 확인에서 실패했다고 했다 → 그 테스트가 멈춤 자체를 잡아낼 수 있는지 판단해 적는다.
3. **M2**: 훅으로 규칙 값을 바꾸는 모든 길(config, 얼린 객체, state·clock 바꿔 끼우기 등)을 직접 시도.
