## 2. 지켜야 할 것
- Easy는 v1과 같은 속도·카드·같은 주제 오답 수여야 한다(spec D2 완료 기준). 단, 오답 감점(Easy −10)은 v2 규칙대로 들어간다.
- 기본 난이도가 Normal로 바뀌고 감점이 생기므로, 기존 테스트(E2 점수 독립 계산, session 등)의 기대값은 **spec 문장으로 다시 계산**해 맞춘다. 저장소 코드 결과를 기대값으로 쓰지 않는다.
- 새 상수는 기존처럼 깊게 얼린다. 테스트 훅으로 난이도 규칙 값을 바꿀 수 없어야 한다.
- 시작 화면에 난이도 줄을 더해도 화면 4종(1180×820, 820×1180, 1024×768, 768×1024)에서 스크롤 없이 들어가야 한다(E6). 새 한국어 문구에는 지난번 만든 어절 묶음(`keepWords`)을 쓴다.
- 이참에 Review 재검토 2의 N3도 고친다: `src/styles.css`의 줄바꿈 주석을 실제 동작(어절 nowrap, 낱말 안에서 끊지 않음)에 맞게.
- spec에 없는 것을 정해야 하면: 사소한 구현 세부는 알아서, 화면·규칙·점수·문구에 영향이 있으면 임시안으로 진행하고 "사용자 결정 필요"로 보고.
