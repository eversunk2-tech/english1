## 3. 담을 것
1. **Very Hard 단어 수준**: "중학교 과정을 심화까지"의 해석과 근거. 2022 개정 [별표 3] 기본 어휘의 중학 권장(**) 전반 + 그보다 높은 심화 낱말(교육과정 목록 밖이면 어디서 근거를 찾을지 — 중학 교과서 수준 등)을 어떤 비율로 쓸지. 원문을 다시 확인.
   - 문항 풀: Very Hard 전용 문항(정답·설명·뜻·avoid)을 새로 만든다(수는 근거와 함께, 한 판 10문제·최근 단어 피하기를 감안해 넉넉히 — 예: 80개 이상). 품질 기준(H1~H4, V 규칙의 Very Hard용 조정)과 판 구성 흉내 확인.
   - 설명(clue): 정답보다 쉬운 말이지만 Very Hard 대상 학생이 읽을 수 있는 수준으로 — 설명 어휘 규칙을 어떻게 바꿀지.
   - **학년 선택과의 관계**: Very Hard에서 학년(3~4 / 5~6 / 모두) 선택이 의미가 있는지(예: Very Hard는 학년과 상관없이 중학 풀, 또는 5~6/모두에서만 열림). 추천과 근거.
   - 오답 카드는 어디서 고를지.
2. **빠르기**: Very Hard 단계 값(카드 수, 떨어지는 시간, 같은 주제 오답 수, 배율, 감점) + 최소 시간 식을 Very Hard에 어떻게 적용할지(읽기 속도 계수 등). "극악"은 피하되 Hard보다 확실히 어렵게. 목표 첫 시도 정답률.
3. **전체 난이도 올리기**: Easy/Normal/Hard 단계 값을 "약간" 빠르게(예: 몇 %) — 전 → 후 표, 근거(사용자 피드백 "Hard도 쉽다"), 최소 시간 보장과의 관계(바닥 때문에 실제로는 안 빨라지는 문항이 많아지지 않는지 — 필요하면 최소 시간 식의 계수 조정도 제안). 각 난이도의 목표 정답률 갱신.
4. **화면**: 시작 화면에 4번째 난이도 버튼(이름·한국어·아이콘), 화면 4종 스크롤 없음, 배지·결과 표시, 최고 점수 칸(학년군 × 4난이도 또는 Very Hard 별도), 도전 권유(Hard → Very Hard).
5. **테스트·Build 단계**(작은 단계, 완료 기준), 바뀌는 기존 테스트.
6. **사용자 확인 필요**: 갈림길 + 추천.
