## 1. 사용자 요청 (원문)
> ui 파운데이션 스킬, ui 레트로 스킬을 이용해 게임 ui 디자인을 수정해줘

## 2. 먼저 할 것
1. **Skill 도구로 두 스킬을 불러 끝까지 읽고 따른다**: `ui-design-foundation:ui-design-foundation`(기반 — 먼저), `ui-style-bold-retro:ui-style-bold-retro`(스타일). 스킬이 다른 파일을 읽으라고 하면 읽는다. 스킬 지시와 이 지침이 부딪히면 이 지침(특히 4절 제약)을 따르고 보고에 적는다.
2. 프로젝트를 파악한다: `CLAUDE.md`, `spec.md`(특히 0, 3, 5.x 화면 관련, 6절 화면 흐름과 문구, 8절, 9절, 10절, 11절 파일 구조, 12.2 E6 배치 검사), 현재 UI 코드(`index.html`, `src/styles.css`, `src/ui/*`, `src/render/canvasRenderer.ts`, `src/render/effects.ts`, `src/ui/hud.ts`).
3. **지금 화면을 직접 본다**: 배포 사이트 `https://eversunk2-tech.github.io/english1/` 또는 로컬 빌드(`npm run build` 후 `node scripts/serve-dist.mjs --dir dist --prefix /english1/ --port 4180` 등)를 Playwright로 열어 시작·손 확인·놀이(터치 모드 `?input=pointer`)·일시정지·결과·오류 화면을 1180×820, 820×1180에서 스크린샷한다.

## 3. 너의 일
게임 UI를 두 스킬 기준으로 다시 디자인하는 계획을 세우고, **시안(mockup)**을 만들어 사용자 승인을 받을 수 있게 한다. 구현은 하지 않는다.
- spec.md에 새 절 "17. v6 UI 디자인 [추천 — 사용자 승인 전]"을 쓴다: 디자인 방향(스킬에서 가져온 원칙을 이 게임에 맞게), 디자인 토큰(색·글꼴·크기·간격·모서리·그림자·테두리·움직임), 화면별 변경(시작, 손 확인, 놀이 HUD·설명 띠·카드·커서·겨냥 빛·점수 숫자·효과, 일시정지, 결과, 오류), 카메라 배경 위 가독성, 접근성(대비 WCAG AA 이상, 글자 크기, 큰 터치 영역, 움직임 줄이기 `prefers-reduced-motion`), 바뀌는 파일 목록, Build 단계(작은 단계·완료 기준), 바뀌는 테스트(E6 배치 등), 사용자 확인 필요(갈림길 + 추천).
- **시안**: `docs/design/v6/`에 시안을 만든다 — 지금 화면과 새 디자인을 비교할 수 있게. 방법은 자유(정적 HTML 목업을 Playwright로 찍기, 또는 실제 빌드 위에 CSS를 덧씌워 찍기). 최소: 시작 화면, 놀이 화면(카드·설명 띠·HUD), 결과 화면 — 가로 1180×820, 세로 820×1180. 가능하면 "지금 vs 새 디자인" 나란히 한 장씩. 스크린샷은 PNG, 시안 원본 HTML도 같은 폴더에. 스크린샷은 직접 열어 확인한다.

## 4. 제약 (엄수)
- **게임 규칙·점수·문구 내용·난이도 값·문항·손 판정은 바꾸지 않는다.** 화면에 보이는 모습만. 문구를 바꿔야 한다고 생각하면 "사용자 확인 필요"로.
- **외부 요청 0 유지**(spec 9절, E1): Google Fonts 등 외부 CDN 글꼴·이미지·스크립트 금지. 글꼴이 필요하면 ① 시스템 글꼴 스택 또는 ② 저장소에 넣어 자체 호스팅(라이선스 OFL 등 확인, 파일 크기, 한글 서브셋)을 비교해 추천. 이미 의존성에 있는 것을 쓸 수 있으면 우선.
- 태블릿(iPad Safari, 안드로이드 Chrome) 성능: 무거운 필터·큰 그림자·매 프레임 레이아웃을 피한다. 캔버스 그리기는 spec 10절 목표 유지.
- 화면 4종(1180×820, 820×1180, 1024×768, 768×1024)에서 스크롤 없음, 한국어 어절 끊김 없음(`keepWords`) 유지. 11자 낱말 카드, 두 줄 설명 띠 유지.
- 카메라 거울 배경 위에서도 카드·설명·커서가 잘 보여야 한다(아이들이 서서 1~2m 떨어져 봄 — 글자 크기·대비 근거).
- 수정 범위: `spec.md`(새 17절, 개정 기록, 14절에 갈림길, 15절에 사용자 원문)와 `docs/design/v6/**`만 만들거나 고친다. `src/**`, `tests/**` 등 코드 수정 금지. git 쓰기·npm install 금지. 빌드·서버 실행은 가능(띄운 서버는 끈다). 임시 파일은 scratchpad `plan-v6`: `/private/tmp/claude-501/-Users-sungchul-Desktop-play2-----/7bd2217c-e14d-425c-9176-0b2e64f9c244/scratchpad/plan-v6`
- 프로젝트 경로에 한글이 있으니 명령에서 항상 따옴표.
