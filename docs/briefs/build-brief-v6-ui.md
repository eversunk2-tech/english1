## 할 일
1. `CLAUDE.md`, spec 17절 전체, 6.2·11·12.2(E11)·12.4-15를 읽고, 시안 그림(`docs/design/v6/compare/*.png`)을 직접 열어 본다. 필요하면 두 스킬(`ui-design-foundation:ui-design-foundation`, `ui-style-bold-retro:ui-style-bold-retro`)도 Skill 도구로 읽는다 — 충돌하면 spec 17절이 기준.
2. 17.12 **U1~U6**을 순서대로. 수정 범위는 17.9의 파일만(spec이 금지한 `strings.ts`·`src/game/*`·`src/hand/*`·`config.ts`는 고치지 않는다 — 꼭 필요하면 멈추고 보고).
3. 지켜야 할 것: 게임 규칙·문구·카드 크기·판정 여유·띠 높이 식 불변, 외부 요청 0(`@font-face`·외부 링크·이미지 파일 없음, 무늬는 CSS, 아이콘은 인라인 SVG), 화면 4종 × 학년 3 × 난이도 4 스크롤 없음·어절 끊김 없음(E6), 대비 4.5:1 이상·포커스 표시·`prefers-reduced-motion`·색만으로 구분하지 않기(E11), 캔버스 그리기 성능(spec 10절 — 매 프레임 그림자 블러 금지, 하드 섀도는 오프셋 채우기로).
4. 테스트: 새 E11, 기존 E1·E2·E6·E8 등 기대값은 바뀌지 않아야 한다(17.10). `npm run check` 종료 코드 0 직접 확인(파이프 없이 `; echo "EXIT=$?"`).
5. 실제 빌드를 화면 4종(1180×820, 820×1180, 1024×768, 768×1024)으로 찍어 시안과 같은 장면(시작, 시작 VH, 손 확인, 3·2·1, 놀이, 오답, 정답, 놓침, 일시정지, 결과, 오류)을 **지금 구현 vs 시안** 나란히 비교 그림으로 만들고 직접 열어 본다.

## 덧붙임 (2026-11-27) — 사용자 결정
- 사용자 원문: "떨어지는 단어들은 그림자 없이 만들어줘". **놀이 화면에서 떨어지는 단어 카드에는 하드 섀도를 그리지 않는다**(정답·오답·겨냥 상태 포함). 검은 테두리·종이 바탕·글자 굵기 등 나머지는 시안대로. 카드가 아닌 것(버튼·띠·START/AGAIN 카드 등)은 시안대로 둔다 — START/AGAIN 카드도 "떨어지는 단어"가 아니므로 그대로. Plan이 spec 17절을 같은 내용으로 고친다.
- 비교 그림에서 이 부분은 시안과 달라도 된다(사용자 결정).
